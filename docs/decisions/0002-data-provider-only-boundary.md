# RemoteLens is a data-provider-only service

RemoteLens will only collect, normalize, filter, and serve attributed job data through its public website and read-only API. CV drafting assistance, process work, application decisions, tracking, and any execution occur locally on a user's computer or a future Mac client, never in RemoteLens services or D1.

## Consequences

- The public API has no user state or write operations.
- The initial Agent Skill has no RemoteLens tracking or application-submission capability.
- Skills and documentation may help a client create truthful, user-reviewed material locally without turning RemoteLens into an execution platform.
